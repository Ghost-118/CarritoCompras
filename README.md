# 👕 Mi Tienda de Ropa - Carrito de Compras

Aplicación web e-commerce de tienda de ropa desarrollada con **ASP.NET Core MVC** y **C#**. Permite visualizar un catálogo interactivo de prendas y gestionar productos dentro de un carrito de compras dinámico.

---

## 🚀 Características

- 🛍️ **Catálogo de Productos:** Visualización de artículos organizados en tarjetas con imagen, título y precio.
- 🛒 **Carrito de Compras:** Funcionalidad para agregar prendas, ajustar cantidades y calcular el importe total automáticamente.
- 🎨 **Diseño Adaptable:** Interfaz moderna y *responsive* desarrollada con Bootstrap 5.

---

## 🛠️ Tecnologías Utilizadas

- **Backend:** C# (.NET 10 / ASP.NET Core MVC)
- **Frontend:** Razor Views (`.cshtml`), HTML5, CSS3, Bootstrap 5
- **IDE:** Microsoft Visual Studio 2022
